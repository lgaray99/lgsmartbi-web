LG-005 / Data Engineering

Pipeline ETL y tablas derivadas

Ejecuta limpieza, normalización y agregación de ventas ficticias y muestra registros rechazados.

Demostración funcional de transformaciones sintéticas
JavaScript (demo)Python/SQL (arquitectura)ETL

Problema empresarial

Fuentes heterogéneas requieren control de tipos, duplicados y validaciones antes de alimentar informes.

Solución representativa

Motor JavaScript de ejemplo que aplica reglas ETL verificables a registros sintéticos y produce un resumen reproducible.

Implementación independiente de demostración. La experiencia y el enfoque técnico se presentan sin reutilizar código o datos de clientes.

Arquitectura

Fuente sintética→Validación→Transformación→Tabla derivada

Beneficios esperados

  • Reglas inspeccionables
  • Separación de válidos y rechazados
  • Reproducibilidad de resultados

Alcance y límites

La demostración se ejecuta con JavaScript y no mueve datos entre bases reales.

Demostración funcional — entorno ficticio

Empresa ficticia: Horizonte Demo S.A. · Moneda: guaraníes (PYG), sin decimales. Todos los nombres, referencias e importes son sintéticos. Las operaciones ocurren en el navegador y no acceden a infraestructura empresarial.
