LG-006 / Data Engineering

Data Warehouse comercial

Explora un esquema estrella coherente, sus claves y agregaciones; descarga CSV y SQL reproducible en PostgreSQL.

Consultas analíticas funcionales con datos sintéticos
PostgreSQL (arquitectura)SQLModelo estrellaJavaScript (demo)

Problema empresarial

Los reportes lentos y los cálculos inconsistentes aparecen cuando cada área interpreta por separado datos operativos.

Solución técnica

Hechos derivados de LG-005 y cuatro dimensiones conformadas, relaciones 1:* verificadas y agregaciones ejecutadas en JavaScript. SQL independiente validado con PostgreSQL WASM de pruebas.

Implementación independiente de demostración. La experiencia y el enfoque técnico se presentan sin reutilizar código o datos de clientes.

Arquitectura

Fuentes operativas→Staging→Hechos y dimensiones→Indicadores

Beneficios esperados

  • Modelo comprensible
  • Indicadores consistentes de ejemplo
  • Separación entre capas

Alcance y límites

El navegador no se conecta a PostgreSQL. Se entrega un script para base local de demostración; no se validó una instalación PostgreSQL nativa ni la operación productiva.

Demostración funcional — entorno ficticio

Empresa ficticia: DemoComercial S.A. · Moneda: guaraníes (PYG), sin decimales. Todos los nombres, referencias e importes son sintéticos. Las operaciones ocurren en el navegador y no acceden a infraestructura empresarial.
