LG-007 / Business Intelligence

Plataforma integral BI y Power BI

Analiza ventas, costos, margen y ticket con cinco dimensiones filtrables y controles de integridad.

Dashboard JavaScript funcional; no es Power BI
Power BI / DAX (experiencia)SQL Server (arquitectura)Python (arquitectura)PostgreSQL (arquitectura)Windows Server (arquitectura)JavaScript (demo)

Problema empresarial

La dirección necesita integrar y analizar información de múltiples sistemas con indicadores estables.

Solución técnica

Motor analítico JavaScript sobre líneas válidas del ETL compartido; filtros combinados, gráficos SVG, detalle exportable y ejemplos de modelo estrella, DAX y Power Query.

Implementación independiente de demostración. La experiencia y el enfoque técnico se presentan sin reutilizar código o datos de clientes.

Arquitectura

SQL Server (conceptual)→Python ETL (conceptual)→PostgreSQL DW (conceptual)→Power BI (conceptual)

Beneficios esperados

  • Experiencia visual navegable
  • Narrativa de arquitectura
  • Interacción con filtros

Alcance y límites

Dashboard estático ejecutable con datos sintéticos. Sin Power BI Service ni archivo PBIX/PBIP validado. DAX y M se entregan como ejemplos pendientes de ejecución en Desktop.

Demostración funcional — entorno ficticio

Empresa ficticia: DemoComercial S.A. · Moneda: guaraníes (PYG), sin decimales. Todos los nombres, referencias e importes son sintéticos. Las operaciones ocurren en el navegador y no acceden a infraestructura empresarial.
